# Маркетплейс — ДЗ №2

Добавлены товары, заказы и промокоды, регистрация и вход с access/refresh-токенами. Права зависят от роли и владельца записи. При заказе товар резервируется, при отмене возвращается на склад. Если операция не прошла, изменения откатываются. Есть проверка входных данных и JSON-логи запросов.

## Как запустить

Нужны Docker с Compose и make. Для демонстрации нужен Python 3. Все команды выполняются из корня проекта.

При первом запуске, если `.env` ещё нет:

```sh
cp .env.example .env
```

Затем:

```sh
docker compose up --build -d --wait
curl http://localhost:8080/health
```

База и миграции запускаются автоматически. Команда `curl` должна вернуть `{"status":"ok"}`. Значения в `.env.example` предназначены только для локальной работы; свой `.env` в Git добавлять не нужно.

## Как пользоваться

API доступно на `http://localhost:8080`. Запросы и форматы данных описаны в [api/openapi.yaml](api/openapi.yaml). Код по этому описанию генерируется при сборке; отдельно, с установленным Go, — командой `make generate`.

Сначала зарегистрируйся через `POST /auth/register` или войди через `POST /auth/login`. Полученный access token передавай в заголовке `Authorization: Bearer <token>`. Для обновления токенов есть `POST /auth/refresh`.

Продавец (`SELLER`) добавляет и меняет свои товары, покупатель (`USER`) оформляет заказы. Администратор (`ADMIN`) создаётся по `BOOTSTRAP_ADMIN_EMAIL` и `BOOTSTRAP_ADMIN_PASSWORD` из `.env`.

Готовый пример «товар → заказ → отмена» и просмотр записей в БД:

```sh
make demo
make db-show
```

В примере остаток меняется с 10 на 8 и обратно на 10.

## Как проверить

После запуска системы выполни E2E-тесты и проверки кода:

```sh
make e2e
docker compose --profile test run --rm --no-deps e2e make test
```

Go для этих команд отдельно устанавливать не нужно. Демонстрация и E2E-тесты добавляют учебные записи в БД и оставляют их после завершения.

## Логи и остановка

```sh
docker compose logs -f user-service commerce-service
```

Ctrl+C завершает просмотр логов. Для остановки приложения с сохранением данных:

```sh
docker compose down
```
